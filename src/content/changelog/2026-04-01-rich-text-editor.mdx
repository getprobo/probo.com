[Documents in Probo](/docs/product/document-management) now have a proper rich text editor. Tables, links, mermaid diagrams, slash commands, auto-save. All built on TipTap.

Previously you were editing markdown. Now you get a real WYSIWYG experience. The editor also renders to PDF using the same prosemirror structure, so what you see is what gets exported.

Existing documents are migrated automatically. Inline editing replaces the old version update dialog, so you just click and write.
