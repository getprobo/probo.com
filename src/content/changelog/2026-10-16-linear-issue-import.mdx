---
title: "Sync Linear issues into Probo tasks"
description: "New Linear issues on the configured team can now create Probo tasks that stay in sync. Set the default team and decide whether imports are active from the task settings."
date: 2026-10-16
images: ["/changelog/2026-10-16-linear-issue-import-1.png"]
tags: ["Integrations"]
---

When issue import is active, each new issue on the selected Linear team creates a Probo task that stays in sync. Task settings let teams choose the default Linear team, control issue imports, or disconnect Linear Sync.
