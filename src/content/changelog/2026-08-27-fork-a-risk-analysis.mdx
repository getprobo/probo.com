Starting a new review period used to mean rebuilding the same scenarios, risks, and treatment plans from scratch. Fork does that copy for you: diagrams, treatment plans, and the relations between them all carry over into a new analysis.

The matrix size stays with the original, so you can't accidentally end up with two analyses on different scales. The new period's dates start empty, ready for you to set them.

It's built for the common case: quarterly or annual [risk reviews](/docs/product/risk-management) that reuse most of the same picture with small updates, not a full rebuild every time.
