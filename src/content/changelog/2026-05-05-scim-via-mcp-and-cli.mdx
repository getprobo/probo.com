---
title: "SCIM via MCP and CLI"
description: "Probo's SCIM management is now reachable from your AI agent and the terminal, so you can script provisioning without the console."
date: 2026-05-05
tags: ["IAM"]
---

MCP gets a [full set of SCIM tools](/docs/developers/api/mcp/tools/catalog/identity-and-provisioning). [The CLI](/docs/developers/cli/commands/scim) gets matching `prb scim` commands. That means you can script user provisioning, deprovision leavers, and sync identity data without touching the console.

If you're running automated onboarding or offboarding flows, this closes the last manual gap.

Released in **0.181.0** — **2026-05-05**
