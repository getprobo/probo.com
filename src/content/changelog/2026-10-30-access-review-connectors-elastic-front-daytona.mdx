This release adds [Elastic Cloud](/docs/product/access-review/elastic-cloud), [Front](/docs/product/access-review/front), and [Daytona](/docs/product/access-review/daytona) to Access Reviews.

Elastic Cloud lists members and API keys with roles and admin status. The API key needs the Organization owner role. Front connects through OAuth or a company API token and lists teammates with their admin status. Daytona lists organization members with an API key, marks owners as admins, and does not include invitations, MFA, or last-login data.
