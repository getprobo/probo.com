[Self-hosting Probo](/docs/deployment/self-hosting) just got a proper Kubernetes path.

The [official Helm chart](/docs/deployment/self-hosting/kubernetes) is out. One command deploys the full Probo stack — server, object storage, ingress, SAML, SMTP, and all your access-review OAuth connectors — fully configurable via values.

Images ship from the artifact.probo.inc OCI registry. Firecrawl is now the only supported web search backend (SearXNG is gone). Access-review connectors require a clientSecret.

If you've been running Probo on raw Kubernetes with hand-rolled manifests, this replaces that. If you've been waiting for a clean self-hosted path before committing — this is it.
