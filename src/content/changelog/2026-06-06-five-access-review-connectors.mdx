[Access reviews](/products/access-review) just got a lot more coverage.

Probo now connects to five more tools your team is likely already using:

- **Zendesk** — with subdomain URL normalization
- **[Okta](/docs/product/access-review/okta)** — authenticated via API key (SSWS)
- **Clerk** — for apps using Clerk for user management
- **SendGrid** — with 2FA enforcement checks built in
- **Datadog** — with region selector and OAuth support

Each connector pulls your user list so Probo can flag who has access to what. No manual exports, no spreadsheets. The reviewer sees the same data your security team does.

If you run access reviews as part of your SOC 2 or ISO 27001 program, these integrations cut the prep work down significantly.
