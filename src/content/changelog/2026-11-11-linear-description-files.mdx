---
title: "Files from Linear issues come into tasks"
description: "Images and files in a Linear issue description are now imported into the linked Probo task, and stay updated when the description changes."
date: 2026-11-11
tags: ["Integrations"]
---

Files embedded in a [Linear](/docs/product/tasks/overview#linear) issue description now show up in the linked Probo task. Probo downloads them when you link the issue and again whenever the description changes in Linear.

Tasks that were linked before this release pick up their files the next time the Linear description is updated.
