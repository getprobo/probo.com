Measures are now [internal controls](/docs/product/compliance-program), with the details teams use to manage them. Each control has a stable code, type, implementation status, owner, and reviewer.

Set an operating frequency, plus separate evidence and testing cadences, to track when work is due. Nature is manual for now.
