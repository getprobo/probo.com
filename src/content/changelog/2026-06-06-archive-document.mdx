Documents you no longer need active can now be archived from the row action menu.

Archiving keeps the document in your system without cluttering your active list. It is non-destructive: archived documents stay accessible if you need to reference them later.

This is the same archive pattern used elsewhere in Probo — consistent behavior, no surprises.

**What changed**

- New "Archive" row action on the [documents list](/docs/product/document-management)
