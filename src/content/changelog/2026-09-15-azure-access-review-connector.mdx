Access Reviews gains Azure. Point the connector at one subscription and it pulls every RBAC assignment, then enriches each principal with last login and MFA state from Entra ID, so you can see at a glance who can touch what.

Setup is one workload identity. Probo spins up an audit role through a portable Terraform azurerm module, so the install matches the AWS and GCP connectors and needs no per-permission fiddling. The source shows up everywhere connectors do: the console, GraphQL, MCP, and the CLI.

Where Entra ID is optional Premium P1/P2, the enrichment comes free. The full picture for Azure access now sits in the same review flow you already run for everyone else.
