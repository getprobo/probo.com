Risk analysis now carry two details that used to live outside Probo, if anywhere. A period start and end date mark the window the analysis actually covers, so it is clear whether you are looking at last quarter's risks or this year's.

The matrix size is explicit too. Pick 3x3, 4x4, or 5x5 for the likelihood and impact scale, and that choice shows up wherever the analysis is listed or viewed. Teams that use different scales for different types of risk no longer have to force everything into the same grid.

Both fields are optional additions to the existing [risk analysis flow](/docs/product/risk-management), not a new workflow to learn.
