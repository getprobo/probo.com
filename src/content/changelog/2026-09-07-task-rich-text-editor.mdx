Task descriptions and comments used to be plain text boxes. Now they run on the same Tiptap editor that powers documents, stored as structured content instead of a flat string.

That means bold, lists, and basic formatting work the way they already do in documents. Comments still speak markdown over MCP, so anything built against the API keeps working the same way.

It's a small change, but it makes task threads easier to read once a discussion has more than a couple of messages.
