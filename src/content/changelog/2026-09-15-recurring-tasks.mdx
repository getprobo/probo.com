Some tasks are one-offs. The rest never really end, and re-creating them every cycle is busywork. Tasks now accept a recurrence interval, so a review that needs to run every quarter can say so on the task itself.

When you mark a recurring task complete, Probo clones the next occurrence automatically and carries the interval forward. You close this month's run and next month's already exists, with the same shape, already queued.

No separate scheduler to wire up, no templates to keep in sync. The cadence lives on the task, and the next one keeps showing up for as long as the work does.
