---
title: "One device, several organizations"
description: "The Probo device agent can now enroll the same machine in more than one organization and report its posture to each one separately."
date: 2026-11-11
tags: ["Devices"]
---

A machine running the [Probo device agent](/docs/product/device-agent/overview) can now be enrolled in more than one organization. It reports its posture to each one separately.

This is for people who work for several companies on the same laptop, like contractors or a fractional CISO. Enrolling the same machine twice in the same organization still fails, and the pending duplicate is revoked.
