Task lists have a new layout. Each row brings status, assignee, linked Linear issue, estimate, deadline, and recurrence into view. Status is editable in place, and drag-and-drop ordering stays.

Deleting a task now happens from its detail page. The list keeps the useful work in view, while the task page handles the more deliberate action.
