[Audits](/docs/product/audits-and-findings) now have a start date and an end date.

Set them when you create or update an audit, and they show up as sortable columns in the audit list across the console, [CLI](/docs/developers/cli/commands/audit), and API. If you run audits over a fixed window, like a quarterly SOC 2 Type II period, you can see that window at a glance instead of opening each audit to check.
