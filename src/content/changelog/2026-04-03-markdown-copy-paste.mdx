Copy markdown from anywhere, paste it into the [Probo editor](/docs/product/document-management), and it renders as rich text. Tables, headers, lists, code blocks. All preserved.

Handy if you're migrating content from Notion, GitHub, or your old wiki. No reformatting needed.
