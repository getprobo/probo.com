Access Reviews keeps growing. This release adds five new connectors: Attio, ElevenLabs, New Relic, Retool, and Twingate.

What ties them together is a simpler setup path. Each of these providers authenticates with a single API key that is bound to one workspace, one organization, or one network. That means no tenant picker in the connect dialog, no choosing between sandbox and production, and no extra scopes to track down. You paste the key and you are done.

For workflows that cross tools, this closes a real gap. Account access often rests on a CRM, a support agent chat, some observability dashboards, and a way into the network, and none of those lived in Access Reviews until now. With these connectors, the same review you already run on cloud and code can cover the SaaS your team actually works from.

The practical effect is a review that reflects where access really is, without the setup friction that used to make people skip a connector entirely.
