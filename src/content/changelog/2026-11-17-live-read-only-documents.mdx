---
title: "Read-only members see live edits"
description: "Members with read-only access to a document now open it live and see other people's edits as they happen. Any change sent from a read-only session is rejected."
date: 2026-11-17
tags: ["Documents"]
---

Members with read-only access to a [document](/docs/product/document-management#review-with-comments-and-suggestions) now open the same live document as editors. When someone else types, the text updates on their screen as it happens.

Read-only still means read-only. Any change sent from a read-only session is rejected.
