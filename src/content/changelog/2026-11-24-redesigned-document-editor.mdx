Each document now opens on a [single page](/docs/product/document-management#the-document-page). The text is laid out on A4 pages, the same as the PDF export, under a fixed formatting toolbar with an insert menu and the mode switch. Properties, linked controls, approvers and signatories sit in a side column you can collapse.

The toolbar shows who else has the document open, and each person's caret gets its own color. In Viewing mode, Versions lists every published version beside the text. Opening one shows it read only and adds a `version` parameter to the URL, so you can link to that exact version.

Publishing asks for a changelog and approvers. Archive, unarchive, delete and Download PDF moved to the page menu. Generated documents open view only and say why.

Old document subpages redirect to the new page, so existing links keep working.
