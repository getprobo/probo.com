Audit and finding evidence shows up in a lot of formats. CSV exports, plain text notes, and Markdown walkthroughs are common enough that downloading and opening each one by hand got tedious.

The console now renders CSV, text, and Markdown evidence files inline. Open the file and read what an audit or finding references without leaving the page to find the download. Formats without a preview render as before.

When evidence is a spreadsheet or a written note, you can verify its contents in the same view where you decide what to do next.
