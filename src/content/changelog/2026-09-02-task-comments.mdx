[Tasks in Probo](/docs/product/compliance-program) used to be a title, a description, and an owner. That covered assigning work but not talking about it. Now every task has a comment thread: description-only notes, ordered oldest first, each one owned by whoever wrote it.

It's available from the CLI (`prb task comment create/list/view/update/delete`), [the n8n node](/docs/developers/api/n8n/resources/task-comment), and GraphQL, so the conversation is queryable the same way the task itself is. There's no rich formatting or attachments yet, just plain text notes tied to the task and the person who wrote them.

Small feature, but it closes a real gap. Questions about a task now live next to the task instead of in a DM someone has to go dig up later.
