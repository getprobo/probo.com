The [Statement of Applicability](/docs/product/compliance-program) used to be an export. A snapshot you'd download and manage outside Probo. That's gone.

The SOA is now a proper document. Edit it in the rich text editor, publish versions, send it for [approval and signature](/docs/product/document-management). Same workflow as every other compliance document. No more exporting PDFs and tracking versions in a folder somewhere.
