[Device enrollment](/docs/product/device-agent/overview) used to drop people straight into organization selection. If you did not have [the Probo agent installed](/docs/product/device-agent/install) yet, you were on your own to find it.

Now there is a step for that. Enrollment shows a dedicated "Download the Probo agent" screen with a link to pro.bo/install before it asks which organization to enroll into.

If the agent is already running on the device, the step gets skipped automatically. No extra clicks, no re-downloading something that is already there.

It is a small fix, but it closes the gap for anyone enrolling a device for the first time and not sure where to start.
