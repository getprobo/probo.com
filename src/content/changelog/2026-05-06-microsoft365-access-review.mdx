You can now use Microsoft 365 as an identity source when creating [access review campaigns](/docs/product/access-review/campaigns) in Probo. Reviewer assignments and access decisions pull directly from your Entra ID directory.

Previously, [access reviews](/products/access-review) required a Google Workspace connection to work with an external identity source. Microsoft 365 organizations can now run the same structured review process without any workarounds.
