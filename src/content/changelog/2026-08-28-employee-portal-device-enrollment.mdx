date: 2026-08-28
images: ["/changelog/2026-08-28-employee-portal-device-enrollment-1.png"]

---

[Device enrollment](/docs/product/device-agent/overview) used to live buried in the console. It's now part of the employee portal, alongside a device list that shows an empty state when there's nothing registered yet.

The registration wizard walks through [downloading the agent](/docs/product/device-agent/install) and enrolling it, step by step. For devices that can't run the agent directly, manual enrollment issues a one-time token with CLI instructions, so IT can still get a device covered.
