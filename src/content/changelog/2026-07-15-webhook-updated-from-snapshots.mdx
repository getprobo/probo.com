---
title: "Webhooks Now Show What Changed"
description: "Update events now include the entity's prior state, so you can diff old vs new values without making a separate lookup call."
date: 2026-07-15
tags: ["Integrations"]
---

[Webhook payloads for update events](/docs/developers/api/webhooks/event-types) just got more useful.

Any star-updated event now includes an updatedFrom field alongside the usual data, carrying a full snapshot of the entity before the update. Want to know if someone's membership role changed from admin to viewer? It is right there, no extra API call needed.

The [Probo Trigger node in n8n](/docs/developers/api/n8n/trigger) picks this up too. Compare the updatedFrom value against the data value directly inside your workflow.
