In the marketplace (connectors list) see which vendors Probo already has connectors for and which ones can still be connected. Open a connector to see the accounts recorded against it.

Disconnecting is refused while an access review source or SCIM configuration still uses that credential. The message names the dependency, so it is clear what needs to change first.
