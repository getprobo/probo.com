Task mentions now sync with Linear in both directions. A mention in a Probo task description or comment appears as a profile link in Linear, and a profile link coming back from Linear becomes a mention chip in Probo.

Resyncing the same document does not notify a person who is already mentioned. An unresolved profile link stays as plain text.
