## Before your first request

1. **Choose the organization.** Records are scoped to an organization; use the identifier required by the operation.
2. **Choose authentication for your client.** Use a supported interactive OAuth flow or a scoped token as described in [API fundamentals](/docs/developers/api-overview).
3. **Start with a read.** Confirm access to the intended records before adding an operation that changes them.

Keep credentials out of source code and logs. Request only the scopes your integration needs.
