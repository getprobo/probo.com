## prb browse

Open Probo in the browser.

### Usage

```text
prb browse
```

### Additional help

```text
Open the Probo console in the default web browser.
```

### Flags

| Flag                 | Type    | Default | Required | Description                                            |
| -------------------- | ------- | ------- | -------- | ------------------------------------------------------ |
| `--no-browser`, `-n` | boolean | `false` | —        | Print the URL instead of opening it                    |
| `--org`              | string  | `""`    | —        | Organization ID (defaults to the current organization) |

### Examples

```bash
# Open the Probo console in the browser
prb browse

# Print the URL without opening the browser
prb browse --no-browser

# Open a specific organization
prb browse --org <org-id>
```
