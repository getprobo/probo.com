### Usage

```text

```

### Flags

| Flag                  | Type        | Default | Required | Description                              |
| --------------------- | ----------- | ------- | -------- | ---------------------------------------- |
| `--amount`            | integer     | `0`     | —        | Asset amount (required, at least 1)      |
| `--asset-type`        | string      | `""`    | —        | Asset type: PHYSICAL, VIRTUAL (required) |
| `--data-types-stored` | string      | `""`    | —        | Data types stored (required)             |
| `--name`              | string      | `""`    | —        | Asset name (required)                    |
| `--org`               | string      | `""`    | —        | Organization ID                          |
| `--owner`             | string      | `""`    | —        | Owner profile ID (required)              |
| `--third-party-ids`   | string list | `[]`    | —        | Third party IDs (comma-separated)        |

### Examples


## prb asset publish

### Usage

```text

```

### Flags

| Flag         | Type         | Default | Required | Description                                                 |
| ------------ | ------------ | ------- | -------- | ----------------------------------------------------------- |
| `--approver` | string array | `[]`    | —        | Approver profile ID (can be repeated; ignored with --minor) |

### Examples
