## prb config set

Update configuration with a value for the given key.

### Usage

```text
prb config set <key> <value>
```

Requires 2 positional arguments.

### Additional help

```text
Update configuration with a value for the given key.

Available keys: editor, browser, pager, prompt, http_timeout
```

### Examples

```bash
# Set the default editor
prb config set editor vim

# Set the HTTP timeout to 60 seconds
prb config set http_timeout 60s

# Disable interactive prompts
prb config set prompt disabled
```
