## prb api

Make an authenticated GraphQL request.

### Usage

```text
prb api <query>
```

Accepts at most 1 positional argument.

### Additional help

```text
Send a GraphQL query or mutation to the Probo API and print the response.
```

### Flags

| Flag            | Type         | Default     | Required | Description                                  |
| --------------- | ------------ | ----------- | -------- | -------------------------------------------- |
| `--field`, `-f` | string array | `[]`        | —        | GraphQL variable in key=value format         |
| `--schema`      | string       | `"console"` | —        | GraphQL schema to query (console or connect) |

### Examples

```bash
# Run a query against the console schema (default)
prb api 'query { viewer { id email } }'

# Run a mutation with variables
prb api 'mutation($input: CreateRiskInput!) { createRisk(input: $input) { riskEdge { node { id } } } }' \
  -f input='{"organizationId":"...","name":"Test","category":"Operational"}'

# Query the connect schema
prb api --schema connect 'query { viewer { id email } }'

# Read query from stdin
echo '{ viewer { id } }' | prb api -
```
