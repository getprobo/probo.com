## prb device list

List ITAM devices in an organization.

### Usage

```text
prb device list
```

Accepts no positional arguments.

### Flags

| Flag                 | Type        | Default  | Required | Description                                                                                 |
| -------------------- | ----------- | -------- | -------- | ------------------------------------------------------------------------------------------- |
| `--after`            | string      | `""`     | —        | Cursor from the previous page (the Next cursor line)                                        |
| `--agent-version`    | string list | `[]`     | —        | Filter by agent version; repeat or comma-separate for multiple                              |
| `--json`             | boolean     | `false`  | —        | Output JSON (same as --output json)                                                         |
| `--limit`, `-L`      | integer     | `30`     | —        | Maximum number of devices to list                                                           |
| `--order-by`         | string      | `""`     | —        | Order by field (CREATED_AT, UPDATED_AT, HOSTNAME, LAST_SEEN_AT)                             |
| `--order-direction`  | string      | `"DESC"` | —        | Sort direction (ASC, DESC)                                                                  |
| `--org`              | string      | `""`     | —        | Organization ID                                                                             |
| `--output`, `-o`     | string      | `""`     | —        | Output format: json, table (default)                                                        |
| `--platform`         | string list | `[]`     | —        | Filter by platform; repeat or comma-separate for multiple (DARWIN, LINUX, FREEBSD, WINDOWS) |
| `--posture-warnings` | boolean     | `false`  | —        | Only devices whose latest posture for some check is FAIL or UNKNOWN                         |
| `--postures`         | boolean     | `false`  | —        | Include latest posture check results                                                        |
| `--query`            | string      | `""`     | —        | Search devices by owner name                                                                |
| `--state`            | string list | `[]`     | —        | Filter by state; repeat or comma-separate for multiple (PENDING, ACTIVE, REVOKED)           |

### Examples

```bash
# List devices in the default organization
prb device list

# List devices with latest posture check results
prb device ls --postures

# List devices sorted by last seen time
prb device ls --order-by LAST_SEEN_AT --output json

# Search devices by owner name
prb device ls --query "Ada"

# List active macOS devices
prb device ls --state ACTIVE --platform DARWIN

# List active and pending devices
prb device ls --state ACTIVE --state PENDING
```
