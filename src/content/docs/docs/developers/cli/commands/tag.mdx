## prb tag attach

Attach a tag to a resource.

### Usage

```text
prb tag attach
```

Accepts no positional arguments.

### Additional help

```text
Attach a tag to a resource. Attaching a tag that is already present is a no-op.
```

### Flags

| Flag            | Type   | Default | Required | Description               |
| --------------- | ------ | ------- | -------- | ------------------------- |
| `--resource-id` | string | `""`    | —        | ID of the resource to tag |
| `--tag-id`      | string | `""`    | —        | ID of the tag to attach   |

### Examples

```bash
# Attach a tag interactively
prb tag attach --resource-id prbdoc_...

# Attach a tag non-interactively
prb tag attach --resource-id prbdoc_... --tag-id prbrtg_...
```

[View command implementation](https://github.com/getprobo/probo/blob/main/pkg/cmd/tag/attach/attach.go#L69).

## prb tag list

List tags in an organization or on a resource.

### Usage

```text
prb tag list
```

Accepts no positional arguments.

### Flags

| Flag                | Type    | Default  | Required | Description                             |
| ------------------- | ------- | -------- | -------- | --------------------------------------- |
| `--after`           | string  | `""`     | —        | Cursor to continue listing from         |
| `--json`            | boolean | `false`  | —        | Output JSON (same as --output json)     |
| `--limit`, `-L`     | integer | `30`     | —        | Maximum number of tags to list          |
| `--order-by`        | string  | `""`     | —        | Order by field (CREATED_AT, NAME)       |
| `--order-direction` | string  | `"DESC"` | —        | Sort direction (ASC, DESC)              |
| `--org`             | string  | `""`     | —        | Organization ID                         |
| `--output`, `-o`    | string  | `""`     | —        | Output format: json, table (default)    |
| `--resource`        | string  | `""`     | —        | Resource ID whose attached tags to list |

### Examples

```bash

```
