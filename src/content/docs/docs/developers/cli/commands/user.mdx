## prb user list

List users in an organization.

### Usage

```text
prb user list
```

Accepts no positional arguments.

### Flags

| Flag                | Type        | Default  | Required | Description                                                                                                                      |
| ------------------- | ----------- | -------- | -------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `--after`           | string      | `""`     | —        | Cursor from the previous page (the Next cursor line)                                                                             |
| `--contract-ended`  | string      | `""`     | —        | Filter by contract status (true or false)                                                                                        |
| `--filter`, `-q`    | string      | `""`     | —        | Filter users by name or email search query                                                                                       |
| `--json`            | boolean     | `false`  | —        | Output JSON (same as --output json)                                                                                              |
| `--kind`            | string      | `""`     | —        | Filter by profile kind (EMPLOYEE, CONTRACTOR, SERVICE_ACCOUNT)                                                                   |
| `--limit`, `-L`     | integer     | `30`     | —        | Maximum number of users to list                                                                                                  |
| `--order-by`        | string      | `""`     | —        | Order by field (FULL_NAME, CREATED_AT, KIND)                                                                                     |
| `--order-direction` | string      | `"DESC"` | —        | Sort direction (ASC, DESC)                                                                                                       |
| `--org`             | string      | `""`     | —        | Organization ID                                                                                                                  |
| `--output`, `-o`    | string      | `""`     | —        | Output format: json, table (default)                                                                                             |
| `--role`            | string      | `""`     | —        | Filter by membership role (OWNER, ADMIN, VIEWER, AUDITOR, EMPLOYEE, COMPLIANCE_PORTAL_MANAGER, COMPLIANCE_PORTAL_ACCESS_MANAGER) |
| `--state`           | string list | `[]`     | —        | Filter by profile state; repeat or comma-separate for multiple (PENDING, ACTIVE, DEACTIVATED)                                    |

### Examples

```bash
# List users in the default organization
prb user list

# List only active users
prb user ls --state ACTIVE

# Search users by name or email
prb user ls --filter alice

# List only admins
prb user ls --role ADMIN

# Filter by type
prb user ls --kind EMPLOYEE

# List users whose contract has ended
prb user ls --contract-ended true
```
