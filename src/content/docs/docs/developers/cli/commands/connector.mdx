## prb connector connect

Create a workload-identity connector.

### Usage

```text
prb connector connect
```

Accepts no positional arguments.

### Flags

| Flag                               | Type    | Default | Required | Description                                                                                                              |
| ---------------------------------- | ------- | ------- | -------- | ------------------------------------------------------------------------------------------------------------------------ |
| `--aws-member-role-name`           | string  | `""`    | —        | IAM role assumed in member accounts                                                                                      |
| `--aws-role-arn`                   | string  | `""`    | —        | IAM role ARN                                                                                                             |
| `--azure-client-id`                | string  | `""`    | —        | Entra application (client) ID                                                                                            |
| `--azure-environment`              | string  | `""`    | —        | Azure environment (AZURE_PUBLIC, AZURE_GOVERNMENT, ...)                                                                  |
| `--azure-subscription-id`          | string  | `""`    | —        | Azure subscription ID                                                                                                    |
| `--azure-tenant-id`                | string  | `""`    | —        | Entra directory (tenant) ID                                                                                              |
| `--gcp-parent`                     | string  | `""`    | —        | Cloud Asset parent (organizations/\{n\} or folders/\{n\})                                                                |
| `--gcp-service-account-email`      | string  | `""`    | —        | GCP service account email to impersonate                                                                                 |
| `--gcp-workload-identity-provider` | string  | `""`    | —        | GCP workload identity provider resource                                                                                  |
| `--json`                           | boolean | `false` | —        | Output JSON (same as --output json)                                                                                      |
| `--name`                           | string  | `""`    | —        | A name that distinguishes this credential from other credentials for the same provider. For example, production or main. |
| `--org`                            | string  | `""`    | —        | Organization ID                                                                                                          |
| `--organization`                   | boolean | `false` | —        | Connect an organization and list its accounts                                                                            |
| `--output`, `-o`                   | string  | `""`    | —        | Output format: json, table (default)                                                                                     |
| `--provider`                       | string  | `""`    | —        | Connector provider (AWS, GCP, AZURE)                                                                                     |

### Examples

```bash
# Connect an AWS account
prb connector connect --name production --provider AWS \
  --aws-role-arn arn:aws:iam::123456789012:role/ProboAudit

# Connect an AWS organization
prb connector connect --organization --name production --provider AWS \
  --aws-role-arn arn:aws:iam::111111111111:role/ProboAudit

# Connect a GCP organization
prb connector connect --organization --name production --provider GCP \
  --gcp-workload-identity-provider projects/123/locations/global/workloadIdentityPools/probo/providers/probo \
  --gcp-service-account-email probo-audit@my-project.iam.gserviceaccount.com \
  --gcp-parent organizations/123456789
```

## prb connector create

Create an API-key or client-credentials connector.

### Usage

```text
prb connector create
```

Accepts no positional arguments.

### Additional help

```text
Creates a connector for a provider that needs no extra setting. A provider that needs a base URL, slug, or region is connected in the console. Use prb connector providers to list the providers this command accepts.
```

### Flags

| Flag              | Type    | Default | Required | Description                                                       |
| ----------------- | ------- | ------- | -------- | ----------------------------------------------------------------- |
| `--api-key`       | string  | `""`    | —        | Customer API key (or PROBO_CONNECTOR_API_KEY)                     |
| `--client-id`     | string  | `""`    | —        | OAuth client ID                                                   |
| `--client-secret` | string  | `""`    | —        | OAuth client secret (or PROBO_CONNECTOR_CLIENT_SECRET)            |
| `--json`          | boolean | `false` | —        | Output JSON (same as --output json)                               |
| `--name`          | string  | `""`    | Required | Name that distinguishes this credential                           |
| `--org`           | string  | `""`    | —        | Organization ID                                                   |
| `--output`, `-o`  | string  | `""`    | —        | Output format: json, table (default)                              |
| `--protocol`      | string  | `""`    | Required | api-key or client-credentials                                     |
| `--provider`      | string  | `""`    | Required | Connector provider                                                |
| `--scope`         | string  | `""`    | —        | OAuth scope. The provider's own scopes win when it declares them. |

### Examples

```bash
# API key from the environment, so it is not a process argument
PROBO_CONNECTOR_API_KEY=<key> prb connector create \
  --protocol api-key --provider NOTION --name production

# Or omit the key and type it at the prompt
prb connector create --protocol api-key --provider NOTION --name production

# Client secret from the environment
PROBO_CONNECTOR_CLIENT_SECRET=<secret> prb connector create \
  --protocol client-credentials --provider MONGODB_ATLAS \
  --name production --client-id <id>

# Or omit the secret and type it at the prompt
prb connector create --protocol client-credentials --provider MONGODB_ATLAS \
  --name production --client-id <id>
```

[View command implementation](https://github.com/getprobo/probo/blob/main/pkg/cmd/connector/create/create.go#L93).
