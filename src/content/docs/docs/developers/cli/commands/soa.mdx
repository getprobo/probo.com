## prb soa statement add

Add an applicability statement to a SoA.

### Usage

```text
prb soa statement add
```

Accepts no positional arguments.

### Flags

| Flag               | Type    | Default | Required | Description                                  |
| ------------------ | ------- | ------- | -------- | -------------------------------------------- |
| `--applicable`     | boolean | `false` | —        | Mark control as applicable                   |
| `--control`        | string  | `""`    | Required | Control ID (required)                        |
| `--justification`  | string  | `""`    | —        | Justification for the applicability decision |
| `--not-applicable` | boolean | `false` | —        | Mark control as not applicable               |
| `--soa`            | string  | `""`    | Required | Statement of applicability ID (required)     |

### Examples

```bash
# Add a control as applicable
prb soa statement add --soa SOA_ID --control CTRL_ID --applicable

# Add a control as not applicable with justification
prb soa statement add --soa SOA_ID --control CTRL_ID --not-applicable --justification "Not in scope"
```

[View command implementation](https://github.com/getprobo/probo/blob/main/pkg/cmd/soa/statement/add/add.go#L78).
