## prb auth login

Authenticate with a Probo host.

### Usage

```text
prb auth login
```

### Flags

| Flag         | Type   | Default | Required | Description                                      |
| ------------ | ------ | ------- | -------- | ------------------------------------------------ |
| `--hostname` | string | `""`    | —        | Probo hostname (e.g. eu.probo.com, us.probo.com) |
| `--org`      | string | `""`    | —        | Default organization ID                          |

### Examples

```bash
# Interactive login (select region, opens browser for device authorization)
prb auth login

# Login to Probo EU
prb auth login --hostname eu.probo.com

# Login to Probo US
prb auth login --hostname us.probo.com

# Login to a self-hosted instance
prb auth login --hostname probo.example.com
```
