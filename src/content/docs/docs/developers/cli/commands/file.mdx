## prb file download

Download a private file.

### Usage

```text
prb file download <id> [path]
```

Accepts 1 to 2 positional arguments.

### Flags

| Flag             | Type    | Default | Required | Description                          |
| ---------------- | ------- | ------- | -------- | ------------------------------------ |
| `--json`         | boolean | `false` | —        | Output JSON (same as --output json)  |
| `--output`, `-o` | string  | `""`    | —        | Output format: json, table (default) |

### Examples

```bash
# Download a file into the current directory
prb file download <id>

# Choose the output path
prb file download <id> ./evidence.pdf

# Write the bytes to stdout
prb file download <id> -
```
