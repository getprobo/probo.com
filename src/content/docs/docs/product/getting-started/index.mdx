## Recommended path

1. Start with the [Product overview](/docs/product/getting-started/product-overview).
2. [Choose a deployment](/docs/product/getting-started/choose-deployment) for your environment.
3. If you are self-hosting, follow the [Quickstart](/docs/product/getting-started/quickstart).
4. [Set up your organization and first framework](/docs/product/getting-started/first-organization-and-framework).
5. Read [Core concepts](/docs/product/getting-started/core-concepts) as you begin working in Probo.
