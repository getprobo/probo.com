## Operate a compliance program

Choose the area that matches your work. Start with the [core concepts](/docs/product/getting-started/core-concepts) if the difference between a control, an internal control, and evidence is new to you.

<div className="docs-resource-list">

| Area                                                           | What you can do                                                                                    |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| [Compliance program](/docs/product/compliance-program)         | Connect frameworks, controls, internal controls, tasks, evidence, and statements of applicability. |
| [Tasks](/docs/product/tasks/overview)                          | Assign work, set deadlines, follow activity, and sync tasks with Linear.                           |
| [Risk management](/docs/product/risk-management)               | Keep a risk register and model threat-based assessments.                                           |
| [Third-party management](/docs/product/third-party-management) | Track vendors, services, contracts, subprocessors, and assessments.                                |
| [Privacy management](/docs/product/privacy-management)         | Document processing activities, data, DPIAs, TIAs, and rights requests.                            |

</div>

## Review and publish

Keep internal review separate from the information you choose to share externally.

<div className="docs-resource-list">

| Area                                                           | What you can do                                                            |
| -------------------------------------------------------------- | -------------------------------------------------------------------------- |
| [Audits and findings](/docs/product/audits-and-findings)       | Scope an audit, connect controls, and follow findings through remediation. |
| [Document management](/docs/product/document-management)       | Manage versions, approval quorums, signatures, publication, and export.    |
| [Compliance Portal](/docs/product/compliance-portal)           | Share selected compliance information with controlled visitor access.      |
| [Assets and obligations](/docs/product/assets-and-obligations) | Inventory important assets and track requirements outside a framework.     |

</div>

## Specialized capabilities

- **Access to Probo:** manage [identity and access](/docs/product/identity-and-access), [SSO](/docs/product/sso/overview), [SCIM](/docs/product/scim/overview), and the [audit log](/docs/product/audit-log).
- **Access to your systems:** run [access-review campaigns](/docs/product/access-review/overview).
- **Website consent:** configure [cookie consent](/docs/product/cookie-banner/overview).
- **Device posture:** collect endpoint security information with [Device Agent](/docs/product/device-agent/overview).

For setup guidance, return to [Get started](/docs/product/getting-started). To automate the same records, see [Developers](/docs/developers).
